Fungsionalitas Edit Tools yang Direplikasi:

📍 Lokasi, Posisi & Bentuk

Koordinat X & Y live update terhadap parent/artboard, W & H dengan aspect ratio lock, rotasi derajat, dan slider / input Corner Radius baik uniform maupun per-4 sudut secara independen.

📐 Auto Layout & Resizing

Arah layout horizontal/vertikal/wrap, 9-point visual alignment box, gap antar elemen, padding terpadu, dan opsi ukuran "Fixed", "Hug contents", serta "Fill container".

✍️ Teks & Font Typography

Pilihan font lengkap (Google Fonts auto-link & system fonts), font-weight, font-size, line-height, letter-spacing, text alignment, text transform, dan text color.

🎨 Warna, Fill, Stroke & Efek

Solid color & gradients, input Hex code + Opacity %, shortcut Eyedropper (I), border stroke inside/outside, dan drop shadow/inner shadow/blur lengkap dengan modal konfigurasi X, Y, Blur, Spread.
